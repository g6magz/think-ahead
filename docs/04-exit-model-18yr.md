No source found for this project shows how that range was built: no volume path, no margin path, no discount rate, no buyer, no share of proceeds, and no statement of whether $750 million to $9 billion is equity value, enterprise value, revenue, or something else. The 18-year clock has **no written start date**.

An external portfolio roll-up dated November 25, 2026, treated Think Ahead’s exit as **unmodeled ($0)** and did not use the $750M–$9B range. That roll-up is not a Think Ahead board document and is noted here only to record that no exit multiple was found in the books it searched.

This file records the stated range exactly as given. It does not invent a model that reaches $750 million or $9 billion.
